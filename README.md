# מעקב הלוואת רכב 📊

דאשבורד בסטייל Grafana למעקב אחרי הלוואת רכב בשיטת **שפיצר** עם **ריבית משתנה
צמודה לפריים** — הריבית מתעדכנת בהתאם להחלטות בנק ישראל, והתשלום החודשי מחושב
מחדש בכל שינוי.

## מה יש בדאשבורד
- **KPIs**: תשלום חודשי נוכחי, ריבית נוכחית, יתרת קרן, התקדמות, ריבית ששולמה, סה״כ ריבית צפויה.
- **גרפים**: ריבית לאורך זמן (פריים מול הריבית האפקטיבית), תשלום חודשי, יתרת קרן (לוח סילוקין), פירוק קרן מול ריבית.
- **שינויי ריבית**: טבלה עם ההשפעה של כל שינוי פריים על התשלום. הפריים נמשך אוטומטית מבנק ישראל (`/api/prime`), עם אפשרות עדכון ידני.

הנתונים נשמרים מקומית בדפדפן (`localStorage`). פריים = ריבית בנק ישראל + 1.5%.

## הרצה
```bash
npm install
npm run dev      # פיתוח
npm run build    # בנייה ל-dist/
```

## משיכה אוטומטית של הריבית
המשיכה עוברת דרך פונקציית שרת ב-`/api/prime` (למשל ב-Vercel), שמושכת את ריבית
בנק ישראל ומחזירה את הפריים. בהרצה מקומית ללא שרת — האפליקציה עוברת אוטומטית
למצב עדכון ידני.
